# Some-Teams-Ivar
A school exercise made by Ivar Fransson Larsson

This is school project about football teams
the project goal is to use php, html and css elements to create a smaller functional website displaying information about these teams.

The site is built on different php documents that are required in. It contains an index.php that displays the main information and a navigation that allows you to click over to the About page that displays information about the creator
